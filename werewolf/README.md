# 🐺 狼人殺邏輯練習器

為真人狼人殺做準備的文字版練習程式。純 Python 3.10+，不需要安裝任何套件。

```bash
python3 -m werewolf                         # 在 repo 根目錄執行
python3 -m unittest werewolf.tests.test_engine   # 執行測試
```

## 功能

| 選單 | 用途 |
| --- | --- |
| 1. 開始一局 | 你扮演一名玩家（可指定或隨機身份），其他座位由電腦扮演。結束後可看**復盤**：所有身份、每晚行動、票型（標示投到狼或好人）、誰是真預言家。 |
| 2. 觀戰模式 | 全電腦對戰；開啟上帝視角可以看到夜晚行動，觀察狼隊怎麼悍跳、好人怎麼找矛盾。 |
| 3. 規則測驗 | 可選主題：基本規則、進階角色、警長競選與自爆，附解說。 |
| 4. 規則速查 | 流程、勝利條件、術語表（金水、查殺、悍跳、倒鉤……）、開局前該問主持人的規則、實戰建議。 |
| 5. 規則設定 | 女巫自救（全程不可／僅首夜／隨時）、同守同救是否死亡、屠邊／屠城、警長競選、狼人自爆。 |

## 板子

- 9 人：3 狼 + 預言家、女巫、獵人 + 3 平民
- 12 人「預女獵白」：4 狼 + 預言家、女巫、獵人、白痴 + 4 平民
- 12 人「預女獵守」：4 狼 + 預言家、女巫、獵人、守衛 + 4 平民
- 12 人「狼王守衛」：狼王 + 3 狼 + 預言家、女巫、獵人、守衛 + 4 平民
- 12 人「攝夢人」：狼王 + 3 狼 + 預言家、女巫、獵人、攝夢人 + 4 平民
- 12 人「奇蹟商人」：狼王 + 3 狼 + 預言家、女巫、獵人、奇蹟商人 + 4 平民
- 12 人「覺醒狼王」：覺醒狼王 + 3 狼 + 預言家、女巫、守衛、攝夢人 + 4 平民
- 15 人「村姑與虎姑婆」：狼美人、虎姑婆、2 小狼、野孩子 + 預言家、女巫、騎士、守衛、村姑 + 5 平民
- 自訂板子：自己輸入每個角色的數量，照真人局的配置練習

## 已實作的規則

- 夜晚順序：守衛 → 狼人 → 女巫 → 預言家
- 守衛不能連續兩晚守同一人；守衛擋不住毒藥；同守同救預設會死
- 女巫一晚只能用一瓶藥；解藥用掉後看不到刀口
- 獵人被狼殺或被放逐可開槍，被毒死不能開槍
- 白痴被放逐時翻牌免死、失去投票權；第二次被放逐才出局
- 平票 → PK（台上的人不能投），再平則無人出局
- 首夜死者有遺言，被放逐、被獵人／狼王帶走的人有遺言
- 狼王：被放逐或晚上出局時發動狼王爪帶走一人；被毒、夢遊出局不能
- 覺醒狼王：兩次狼王爪，晚上可親傳一爪給狼隊友（每晚一次、每人最多一次），剩下的出局時全部可用
- 攝夢人：每晚必選一人夢遊，夢遊者當晚免疫狼刀與毒藥；連續兩晚同一人 → 出局；攝夢人晚上死亡 → 夢遊者一起出局
- 奇蹟商人：整局一次把查驗／毒藥／守護交給一人（幸運兒，當晚可用一次）；交給狼人則交易失敗、商人天亮出局
- 被獵人或狼王帶走的獵人／狼王，也可以接著發動技能
- 狼美人：每晚迷魅一人（不能連續同一人），狼美人出局時被迷魅者一同出局；狼美人不能自爆
- 虎姑婆：第二晚起每隔一晚誘導（預言家與村姑只能驗該號碼與左右兩人，範圍不可與上次重疊）；整局一次惡靈反傷（村姑 > 預言家 > 女巫）
- 野孩子：首夜選榜樣，榜樣出局後轉狼；被驗永遠金水；轉狼後好人不用放逐他
- 騎士：白天發言時可決鬥一次，對方是狼則出局並立刻天黑，是好人則騎士出局
- 村姑：整局一次查驗，準確度依她的警長票／放逐票而定
- 屠邊時村姑、野孩子不算神職也不算平民
- 警長競選（第一天、公布死訊前）：上警、警上發言、警下投票、平票 PK、再平流失；警長 1.5 票、決定發言方向並最後發言、出局時移交或撕警徽
- 狼人自爆：輪到自己發言時（含警上）可自爆，立即出局、無遺言、當天直接天黑；狼王自爆可帶人；警上自爆警徽流失
- 警長與自爆可在「規則設定」裡關閉

## 電腦玩家怎麼思考

電腦只用它的身份「應該知道」的資訊：

- 狼隊開局約 60% 機率派一隻狼**悍跳預言家**，常對真預言家發查殺、給隊友發金水；被指認時偶爾會假跳獵人；投票時全隊統一。
- 好人會**找矛盾**：「有人查殺我，但我是好人 → 他是假預言家」、「有人說翻牌白痴是狼 → 他說謊」；並參考票型（投給可信者的人可疑），只採信自己不懷疑的人的指認。
- 預言家通常第一天起跳報查驗；女巫首夜大多會救人；守衛會守自己相信的預言家。

## 檔案

- `roles.py`：角色、陣營、板子
- `engine.py`：規則與流程（不含輸入輸出，方便測試）
- `bots.py`：電腦玩家策略
- `human.py`：真人輸入
- `guide.py`：規則速查、術語、測驗題
- `cli.py`：主選單與復盤

## 網頁版

`web/index.html` 是手機也能玩的單頁版本，規則和電腦策略與 Python 版相同。
測驗題以 `guide.py` 為準，修改題目後執行 `python3 werewolf/web/sync_quiz.py` 同步到網頁版。

`web/index.html` 是 Claude 網頁（Artifact）用的原始檔，沒有 doctype、viewport 等外層標籤。
GitHub Pages 用的是 `play/index.html`，由 `python3 werewolf/web/build_pages.py` 產生；
