## 狼人殺推理筆記（`werewolf/`）
12 人局玩家用的個人推理筆記，適合 iPad。純前端、離線可用，資料存在瀏覽器本機。
用 Safari 開啟 `werewolf/index.html`（GitHub Pages：`/jackh_code/werewolf/`），按「分享 → 加入主畫面」即可全螢幕使用。

## 狼人殺邏輯練習器
- 網頁版（手機可玩）：GitHub Pages `/jackh_code/werewolf/play/`
- Python 版：`python3 -m werewolf`，說明見 `werewolf/README.md`
